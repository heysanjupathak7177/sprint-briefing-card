⚡ What is StoryIQ?

StoryIQ is a zero-cost BA story quality engine. It uses your existing Claude.ai subscription to analyse user stories from 4 different perspectives simultaneously — Developer, QA Engineer, End User, and Client — and detects where they conflict before grooming starts.

🧑‍💻
Developer view
How the dev will interpret the story and what assumptions they'll make
🧪
QA Engineer view
What test cases QA will write and what edge cases they'll miss
👤
End User view
How the actual user will experience this feature and where they'll get confused
💼
Client view
What the client expects vs what's actually being built
📋 How to use — 4 steps
Step 1 — Paste your user story into the Analyser tab
Step 2 — Click "Generate prompt" — StoryIQ builds the perfect Claude prompt automatically
Step 3 — Copy the prompt → paste into Claude.ai → copy Claude's response
Step 4 — Paste the response back → StoryIQ displays your full analysis beautifully

Cost: £0. Uses your existing Claude.ai subscription.
