⚡ What is StoryIQ?

StoryIQ is a BA story quality engine. It analyses user stories from 4 different perspectives simultaneously — Developer, QA Engineer, End User, and Client — and detects where they conflict before grooming starts. Automatic Mode fetches the ticket from Jira, sends it to your chosen AI model, and displays the result with no copy-paste.

🔑 Setting up Automatic Mode
1. Click "Credentials" top-right
2. Enter your Jira site, email, and API token
3. Choose Claude or Grok, and paste that provider's API key
4. If Jira calls fail with a network/CORS error, enter your proxy URL (see the note in the Credentials modal) — this is required because browsers block direct calls to Jira's API
5. Type a ticket key in the Analyser tab and click "Fetch & Analyse"
💡 Pro tips
• Run every story through StoryIQ before grooming — save 30 mins per story
• Check the Trends tab weekly — track your quality score improvement
• Use "Push to Jira as comment" to leave the analysis directly on the ticket
• Your credentials and history are stored only in this browser — never sent anywhere except Jira/your AI provider directly
• The manual copy/paste flow (switch via the link on the Automatic Mode card) still works if you don't want to store API keys
